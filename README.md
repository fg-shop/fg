# SorveX Mail

Static GitHub-ready version of the SorveX Mail landing/category page.

## Files

- `index.html` — main page
- `style.css` — custom CSS and animations
- `script.js` — category filter and currency UI
- `uploads/` — place your logo, favicon and category icons here

## Important

The original PHP links were changed to static `.html` links for GitHub Pages:

- `index.php` → `index.html`
- `login.php` → `login.html`
- `register.php` → `register.html`

Tailwind CSS, Google Fonts and Font Awesome are loaded from their CDNs.
